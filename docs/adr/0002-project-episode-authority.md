# ADR 0002: Model series as project, season and episode authorities

- Status: Accepted
- Date: 2026-08-29

## Decision

Projects own reusable assets and the story bible. Seasons own a season arc.
Episodes own outlines, versioned scripts, production runs, and end-state
continuity snapshots. Starting a run creates an immutable snapshot so later
project edits cannot mutate historical episodes.
