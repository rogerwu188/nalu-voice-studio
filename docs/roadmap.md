# Nalu Voice Studio roadmap

## 0.1 — Productized interface

- Stable Project → Season → Episode domain model
- Script revision and approval contract
- Project asset registry and consent metadata
- Continuity snapshots and immutable production packages
- Dry-run Qingshan adapter
- Local OpenAPI service and contract tests

## 0.2 — Native voice intake

- SwiftUI macOS client
- Push-to-talk interview mode
- Local transcript and one-question-at-a-time flow
- Story-to-season planning and spoken script approval
- Photo and audio authorization flow

## 0.3 — Controlled production

- Qingshan preflight invocation
- Durable transaction submitter integration
- Live production events, retry and recovery
- Human review gates for script, cost, media and release

## 0.4 — Series continuity and release

- Episode end-state extraction
- Cross-episode continuity audit
- Final master, cover, captions and release package
- Guardian controls and accessibility verification
