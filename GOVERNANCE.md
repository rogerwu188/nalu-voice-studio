# Governance

Nalu Voice Studio uses a maintainer-led model during its pre-1.0 phase.
Maintainers set release scope, review safety-sensitive changes, and protect API
compatibility. Routine decisions happen in issues and pull requests. Major
architecture decisions are recorded under `docs/adr/`.

A change requires two maintainer reviews when it affects paid generation,
publishing, biometric consent, child safety, or release-blocking QA policy.
